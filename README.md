# E-commerce Brazil Analysis Project

## Overview

This project provides an interactive analysis of e-commerce transactions in Brazil, leveraging Streamlit for a user-friendly interface. The analysis focuses on understanding customer behaviors, sales trends, and order statuses, to help businesses make data-driven decisions.

## Features

- **Interactive Dashboard**: Users can explore data through an easy-to-use interface built with Streamlit.
- **Data Visualization**: Visualizations of daily orders, customer spending, order statuses, and geographical distribution of orders.
- **User Filtering**: Users can filter data based on date ranges to analyze specific periods.
- **Customer Insights**: Demographics and order review scores are presented to understand customer satisfaction.

## Technologies Used

- **Python**: Main programming language for data processing and analysis.
- **Streamlit**: Framework for building the web application.
- **Pandas**: Library for data manipulation and analysis.
- **Matplotlib** and **Seaborn**: Libraries for data visualization.

### Usage
To run the application, use the following command:
```bash
   cd dashboard
    streamlit run dashboard.py
```
Once the application starts, it will be accessible at http://localhost:8501 in your web browser.
